# intro.html source

React source for `intro.html`, the four-screen overview used on interview screen shares.
Components are adapted from the freedesignmd library (MIT, © 2026 Tammo Elsner): SplitText, CountUpStats (Odometer), ProcessTimeline, MinimalSignoffFooter.

Rebuild: `cd intro-src && npm install && npm run build` (writes `../intro/app.js`). Page styles live in `intro.html`.
